# 🧠 MindVault

MindVault is a web application designed to help users securely manage and organize their memories, notes, and personal information in one place.

## 🚀 Features

- 🔐 User authentication
- 🧠 Create and manage memories
- 📝 Add and edit personal notes
- 📂 Organize memories into collections
- 🔍 Search memories
- 👤 User profile
- 🗑️ Deleted memories management
- 🔑 Password reset functionality
- 📱 Responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Node.js
- npm
- Git & GitHub
